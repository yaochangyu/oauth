# 個人基本資料維護操作指南

本指南引導您如何在會員中心查看並修改您的暱稱與個人大頭貼。

## 操作流程圖

[檢視操作流程圖 (HTML)](./diagram.html)

## 操作步驟

1. **進入個人帳號設定**
   在網站畫面右上角點擊您的個人頭像，選擇「個人帳號設定」。

2. **檢視個人資料**
   進入設定頁面後，畫面會顯示您的註冊電子郵件、目前的暱稱與大頭貼圖片。

3. **修改暱稱與頭像**
   - 在「個人暱稱」輸入框中輸入您希望顯示的新稱呼。
   - 在「頭像圖片網址」欄位貼上您的大頭貼圖片連結。

4. **儲存變更**
   點擊下方的綠色「儲存變更」按鈕。畫面跳出「更新成功」提示即完成修改。

## 常見狀況與排除方法

- **提示「暱稱不可為空」** → 暱稱欄位為必填項目 → 請輸入至少 1 個字元的暱稱。
- **新大頭貼圖片未顯示** → 圖片連結可能無效或外部防盜鏈阻擋 → 請確認圖片網址為公開可存取的圖片連結。
