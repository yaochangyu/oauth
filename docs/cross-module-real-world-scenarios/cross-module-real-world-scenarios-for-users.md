# 跨模組真實情境操作手冊

本手冊為您介紹從註冊會員帳號、在第三方網站使用會員登入、授權存取個人資料，到日後管理並解除授權的完整生活使用情境。

## 操作步驟

1. **建立新會員帳號**
   在認證中心首頁填寫您的電子信箱、設定密碼與個人暱稱，完成會員帳號註冊。

2. **在合作網站點擊登入**
   前往合作夥伴網站或手機 App，在登入畫面點擊「使用帳號登入」按鈕。

3. **登入您的帳號**
   畫面將跳轉至官方認證頁面，輸入您的 Email 與密碼後點擊「登入」。

4. **確認授權內容並同意**
   畫面上會列出該合作網站希望取得的權限（例如：讀取您的基本姓名與信箱）。確認無誤後，點擊綠色的「同意授權」按鈕。

5. **自動跳回合作網站並開始使用**
   系統將自動轉跳回原合作網站，您會看到個人頭像與歡迎文字，已成功完成登入。

6. **日後解除網站授權**
   若您不再使用該網站，可隨時登入「個人帳號中心」→「已授權應用管理」，找到該網站並點擊「解除授權」。解除後該網站將立即失去存取您資料的權限。

## 常見狀況與排除方法

- **在授權頁面點擊拒絕** → 畫面會跳回合作網站並提示「使用者已取消授權」 → 合作網站無法取得您的帳號資料，無法完成登入 → 如欲繼續使用，請重新點擊登入並選擇同意授權。
- **解除授權後合作網站仍顯示已登入** → 合作網站本地端可能暫存了舊資料 → 當合作網站下次嘗試連線更新資料時將會失效並自動登出。
