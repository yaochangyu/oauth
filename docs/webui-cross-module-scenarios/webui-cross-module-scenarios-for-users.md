# 跨系統登入與授權生活化操作指南

本指南介紹一般使用者在日常使用各種網站（包括一般購物網站與現代化單頁網站）時，如何透過統一的會員帳號完成登入與授權的完整情境。

## 操作步驟

1. **從第三方網站發起登入**
   在合作網站首頁點選「使用會員帳號登入」。

2. **註冊或直接登入**
   系統自動開啟登入畫面。若為新會員，點擊「註冊帳號」填入信箱與密碼即完成建立；若已有帳號直接輸入密碼登入。

3. **處理授權同意頁面**
   - **首次登入該網站**：畫面上會列出網站名稱與權限請求，確認後點擊「同意授權」。
   - **再次登入或常用網站**：系統已記得您的選擇，將自動登入並略過確認頁。
   - **不想授權**：點擊「拒絕」，畫面將返回原網站並提示授權取消。

4. **開始在網站中瀏覽**
   回到原網站後，右上角顯示您的個人暱稱與頭像，即可開始使用網站提供的各項功能。

## 常見狀況與排除方法

- **點擊同意後網頁一直轉圈** → 網路瞬斷或瀏覽器忙碌 → 請重新整理網頁或稍候 2 秒。
- **不想每次登入都按同意** → 在同意頁面勾選「記住我的選擇」或點擊同意，後續登入系統將自動為您放行。
